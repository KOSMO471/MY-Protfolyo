# 🚀 Mehmet Fatih - Kişisel Portfolyo & CV

Modern, sade ve gerçek verilerle kurgulanmış kişisel portfolyo web sitem. Masaüstü uygulamalarından oyun kurgusuna, algoritma tasarımından otomasyon projelerine kadar geliştirdiğim çalışmalar burada yer alıyor.

## 🛠️ Kullanılan Teknolojiler
* **HTML5 & CSS3** (Özel Tasarım, Flexbox/Grid, Glassmorphism Efektleri)
* **JavaScript (ES6+)** (İnteraktif Filtrelemeler, Modal Yapıları)
* **Font Awesome** (İkon Setleri)

* **Manifesto & Yaklaşım Kartı:** Yazılım felsefemi yansıtan özel alan.

* **Eğitmen Görüşleri Filtresi:** Aldığım resmi geri bildirimleri eğitmene göre filtreleme imkanı.
* **Sertifika Galerisi:** Başarı belgelerimin büyük boy açılabilen modal önizlemesi.
